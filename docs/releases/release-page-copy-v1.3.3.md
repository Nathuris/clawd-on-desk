## v1.3.3（个人定制版）

从上游 v1.2.0 起，这个仓库只改了一件事：**点桌宠弹出的那块面板**。

**面板 = 终端里那个会话的远程输入框**

在这里打字回车，内容会被投递进终端 App 里正在跑的会话——真正的对话仍然发生在
终端里。左边「＋」挂附件（选文件或 ⌘V 粘贴图片），右边「⚙」开设置。

**能看见、也能改终端里那个会话的真实状态**

- 设置菜单顶部那行显示终端里**真实的**权限模式与思考强度，不是面板里选的那个
  "下次新建会话"用的档位；拿不到就写「未知」，不拿别的值顶上。
- 拖动强度滑块**松手**时，官方的 `/effort` 命令会送进那个会话，立刻就改。送不
  进去会如实说明，**不会**退化成"悄悄复制到剪贴板、再把终端抢到前面"。
- 权限模式面板不代劳（官方只有 Shift+Tab 循环切换）。

**会话列表**

- **能滚了**，有几个会话列几个；「＋ 新建会话」「📁 选择文件夹」钉在卡片下沿不跟着滚。
- **「最近」那一组**：列出已经结束、还能接着聊的会话，**点一下就在终端里把它重新
  拉起来**；拉不起来会如实说卡在哪一步。
- **置顶**：鼠标移到任意一行，行尾冒出一个小 📌，点一下钉在列表最上面，
  **重启应用还在**。正在跑的和历史的都能钉。

**右键菜单**：去掉了「打开足迹」（它仍然在设置里），加上「自由漫步」一键开关。

**安装**：`Clawd-on-Desk-1.3.3-arm64.dmg`（Apple 芯片，M 系列）。
本地编译、未签名，双击即可打开；第一次会弹「允许控制终端」的授权，点允许
（面板要把消息投递进终端 App）。

**说明**：这是个人定制版，版本号与上游对不上；自动更新检查指向上游仓库，
不会提示更新。
