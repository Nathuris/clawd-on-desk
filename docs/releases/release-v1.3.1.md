## v1.3.1

个人定制版（fork）的一小步：**面板能看见终端里那个会话真实的权限模式与思考强度**。

### 面板：多一行"终端里现在是什么"

- 设置菜单最上面多了只读的一行，例如「终端里：计划 · 高」。它读的是会话自己
  报上来的值，不是面板里选的那两个"下一次新建会话"的档位——以前两边各说各话，
  现在你能一眼看出终端里到底在什么模式。
- 面板自己那 4 档之外的模式（`dontAsk`「不用问」、`bypassPermissions`「跳过确认」）
  也如实显示；会话还没上报过就显示「未知」，绝不拿别的值顶上。
- 目标是排队中的新会话时，这行显示「新会话：…」，也就是它开起来时会带的档位。

### 数据来源（新增）

- `hooks/clawd-hook.js` 开始上报 `permission_mode` 与 `effort`（Claude Code 的
  hook 载荷里本来就带着；SessionStart 没有这两个字段，Stop 才带 effort）。
- `hooks/session-mode-fields.js`：新增的小模块，卡白名单（`manual` 归一成内部的
  `default`），服务端 `src/server-route-state.js` 复用同一份，避免两边写两套。
- `src/state.js` 按粘性合并存下来（后面的事件不带也不会被清空），快照
  `src/state-session-snapshot.js` 暴露这两个字段并计入签名（否则面板不会刷新）。

### 这一版还**没有**做的事

面板上选强度/权限模式**仍然只影响下一次新建的会话**——直接改正在运行的那个会话
是下一步（强度可以通过 Claude Code 官方的 `/effort` 命令做到；权限模式官方只提供
Shift+Tab 循环切换，暂时不做控制，只在菜单那行提示你）。
