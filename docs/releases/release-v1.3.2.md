## v1.3.2

个人定制版（fork）：**面板上的强度滑块，现在直接改终端里正在跑的那个会话**。

### 强度：从"只管新会话"变成"直接改现在这个"

- 拖动面板设置菜单里的强度滑块，**松手**（不是每拖一格）时，应用会把 Claude Code
  官方的 `/effort <档位>` 命令送进目标会话所在的终端标签页——立刻就改，只对这个
  会话生效。拖动过程中只更新"新会话默认档位"，不会一路发命令。
- 目标是排队中的新会话 / 还没有会话时，维持原样：只记成新会话的启动参数。

### 送不进去就说送不进去（这条是刻意的）

- 控制命令走**单独一条投递链**（`src/session-control-send.js`），只认"真的写进终端
  了"。送不进去**不会**像聊天内容那样退化成"复制到剪贴板 + 把终端抢到前面"——
  那样用户完全看不懂发生了什么，剪贴板里还躺着一句 `/effort xhigh` 等着被误粘。
- 够不着的目标一律拒绝并说明：不是 Claude Code 的会话、远程/WSL、没有终端的
  headless、标签页已经回到 shell。面板状态行会如实显示「没能改：请到终端里自己敲
  /effort」或「这个会话不支持面板改强度」。

### 权限模式：仍然只影响新会话（不是漏做）

- Claude Code 没有"直接切到某个模式"的命令，只有 Shift+Tab 循环切换；而循环里
  会不会出现"跳过确认/自动"取决于会话条件，外部读不到，盲猜步数有把会话切到**更
  宽松**模式的风险。所以面板不代劳——设置菜单里那行状态会一直显示终端里真实的
  模式，换模式请在终端里按 Shift+Tab。

### 上一版（1.3.1）已有的

- 设置菜单顶部那行只读状态：「终端里：计划 · 高」，读的是会话自己上报的值；
  面板没有的档（不用问 / 跳过确认）也如实显示，拿不到就显示「未知」。
