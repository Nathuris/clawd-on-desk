## v1.3.4

个人定制版（fork）：修两个 1.3.3 带出来的毛病——**改过的会话名字关掉后不见了**，
以及**续跑回来的会话在面板里出现两次**。

### 改过的名字，会话关掉之后还在

- 你用 Dashboard 给会话起过名字（双击标题改的那个），会话一关，名字就丢了：
  面板和 Dashboard 的历史列表退回成**一串会话编号**（看着就像乱码），或者变成
  你当时打的第一句话那一长串。原因是历史列表的名字是从**对话记录里现读的**，
  压根没去查你起过的名字。
- 现在历史列表**先查你起过的名字**，查到就用它。会话还活着时起的名字，关掉之后
  照样认得出来（两边用的是同一套对应关系）。

### 续跑回来的会话，在面板里只剩一条

- 面板的历史列表是**缓存的**（免得每次会话状态变一下都去读磁盘）。会话刚被拉起来
  的那一刻，缓存里那行还以为自己是"历史"，于是面板同时显示了一行历史 + 一行刚
  起来的活会话——看着就像"多出了一个同名的会话"。
- 现在每次刷新面板都会拿**当前活着的会话**再滤一遍：那个会话只要活了，历史里那行
  立刻消失。

### 「已提交，等终端上报」不会永远挂着

- 点了续跑、终端里还要你手动信任文件夹，会话迟迟不上报时，那行字原本会一直写着
  "已提交"不动。现在有 30 秒的确认窗：过了还没等到就改口说
  「**还没等到终端上报，可以再试一次**」，并且重新可以点。

### 上一版（1.3.3）已有的

- 面板的会话列表能滚，「＋ 新建会话 / 📁 选择文件夹」钉在卡片下沿。
- 「最近」那一组列出已结束的会话，点一下就能在终端里重新拉起来。
- 会话置顶：每行一个 📌，重启还在。
- 右键菜单：去掉「打开足迹」，加上「自由漫步」一键开关。
