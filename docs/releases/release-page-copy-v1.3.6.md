## v1.3.6（个人定制版）

这一版修面板发消息的一个大毛病：**长文字（或者带文件路径的）发出去之后，会停在
终端输入框里不发送**——得再切到终端手动按一次回车才发得出去。短消息没事，越长越容易中招。

**为什么会卡住**

面板是把整段字**一口气**塞进终端标签页的。claude 收到这种"一大团瞬间到达"的输入会
当成**粘贴**处理，末尾那个"按发送"的回车就被算成粘贴内容的一部分了，变成输入框里的
一个换行，消息于是停在原地。

**怎么修的**

消息送进去之后，隔 0.35 秒补一个独立到达的回车，再隔 1.3 秒补第二个兜底——
字越多 claude 消化得越慢，第二个回车专门等它落定。补在空输入框上的回车什么也不做，
所以短消息不受任何影响。

---

**这个 fork 是什么**：从上游 v1.2.0 起，只改了点桌宠弹出的那块面板——它是**终端里
那个会话的远程输入框**，同时能看能改终端里的真实状态。

- 设置菜单顶部显示终端里**真实的**权限模式与思考强度；拖动强度滑块松手时，官方的
  `/effort` 命令会送进那个会话，立刻就改。
- 会话列表能滚，「＋ 新建会话 / 📁 选择文件夹」钉在卡片下沿。
- 「最近」那一组列出已结束的会话，点一下就在终端里重新拉起来。
- 置顶：每行一个 📌，钉在最上面，重启还在。
- 右键菜单里有「自由漫步」一键开关。

**安装**：`Clawd-on-Desk-1.3.6-arm64.dmg`（Apple 芯片，M 系列）。本地编译、未签名，
双击即可打开；第一次会弹「允许控制终端」的授权，点允许（面板要把消息投递进终端 App）。

**说明**：个人定制版，版本号与上游对不上；自动更新检查指向上游仓库，不会提示更新。
