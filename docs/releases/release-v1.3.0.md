## v1.3.0

这一版是 **个人定制版（fork）** 的版本号：上游 v1.2.0 之后，本仓库只做了面板
（点桌宠弹出的那个输入卡片）的本地改动，没有合并上游 v1.2.1 之后的内容。

单独给一个版本号，是为了让本机编译出来的安装包和上游的 v1.2.0 安装包在文件名上
区分开，两个包可以并存互不覆盖。

### 面板：改成「macOS 终端 App 的远程输入框」

- 面板不再自己聊天：输入的内容由主进程投递到终端 App 里正在运行的 CLI 会话，
  真正的对话仍发生在终端里（面板只是远程输入框）。
- 点「新建会话」先在列表里排一个位，真正开终端推迟到发送第一条消息时。
- 一个会话都没有时，直接发消息会自动开一个新会话。

### 面板：附件与菜单

- 附件改成输入框上方的一行小标签，路径不再塞进输入框；支持选文件与 ⌘V 粘贴图片。
- 会话菜单（会话 / 新建 / 选文件夹）与设置菜单（权限模式 + 思考强度）拆成两张
  独立的浮层卡片，点开淡入，主卡片的位置与高度不变。
- 「＋」在输入框左侧、「⚙」在右侧，两个同款方块按钮；权限模式改成大字名称 +
  小字说明的列表，强度改成 5 档拖动滑块。

### 面板：位置与热区

- 卡片整体比桌宠中心下移 12px，展开时依然只向上长。
- 修复：桌宠贴屏幕下沿时，面板会「先出现在偏上、再往下蹦一下」，并因此导致热区
  与眼睛看到的卡片错位、面板不肯自动收起。现在整扇窗口（含底部 60px 输入法净空）
  都会被夹在工作区内。

### 其他

- 名单内编辑器窗口可见时不弹权限气泡。
- 删掉了内置 Claude 客户端（自己的聊天窗口、Agent SDK 驱动、历史续聊、附件通道、
  回复窗口自动消失那一整套），连同对应测试；这些功能已无入口。
- 偏好设置 v21 → v22 清理上述功能的残留键。

### 与本机使用相关的说明

- 这个包是**本地编译、未签名**的（`mac.identity: "-"`）。自己编译出来的包不会带
  quarantine 标记，双击即可打开；如果是从别处拷贝过来的，需要在「系统设置 → 隐私
  与安全性」里放行一次，或执行 `xattr -dr com.apple.quarantine` 去掉隔离标记。
- 首次运行仍会弹出「允许控制终端」的系统授权（面板要把消息投递进终端 App）。
- 自动更新检查指向的是上游仓库 `rullerzhou-afk/clawd-on-desk`。本包版本号高于上游
  当前版本，因此不会提示更新；若将来上游发布了同号或更高的版本，请勿直接更新，
  否则会把定制版覆盖成官方版。
