# GitHub Release 页文案（v1.3.0 – v1.3.3）

给 GitHub 上「Create a new release」的说明框用的**短文案**。发第几个版本就复制
对应那一段，粘进 release 的说明框即可。

- Tag：和版本号同名（`v1.3.0`、`v1.3.1`…）。用网页新建 release 时，在
  「Choose a tag」里输入 `v1.3.0` 然后选 **Create new tag: v1.3.0 on publish**。
- 附件：把 `dist/Clawd-on-Desk-<版本>-arm64.dmg` 拖进 Attach binaries。
  （`.zip` 和 `.blockmap` 是自动更新用的，自己用不上，不用传。）
- 标题就写版本号本身（例如 `v1.3.3`）。

---

## v1.3.0

个人定制版的第一个独立版本号：上游 v1.2.0 之后，这个仓库只改了面板（点桌宠弹出
的那个输入卡片）。单独给版本号，是为了让本地编译的安装包和上游 v1.2.0 的包在
文件名上区分开，两个可以并存互不覆盖。

- **面板改成「终端 App 的远程输入框」**：输入的话由桌宠投递进终端里正在跑的
  会话，真正的对话仍然发生在终端里。
- 「新建会话」先在列表里排一位，真正开终端推迟到发出第一条消息时。
- 附件改成输入框上方的一行小标签，路径不再塞进输入框；支持选文件和 ⌘V 粘贴图片。
- 会话菜单与设置菜单拆成两张独立的浮层卡片；权限模式是大字名称 + 小字说明的列表，
  思考强度是 5 档拖动滑块。
- 「＋」在输入框左侧、「⚙」在右侧。
- 修复：桌宠贴屏幕下沿时，面板会「先出现在偏上一点、再往下蹦一下」，并因此导致
  热区与肉眼所见错位、面板不肯自动收起。

**安装**：`Clawd-on-Desk-1.3.0-arm64.dmg`（Apple 芯片）。本地编译、未签名，
双击即可打开。

## v1.3.1

- 设置菜单顶部多了一行只读状态，例如「**终端里：计划 · 高**」——显示的是**终端里
  那个会话真实的权限模式与思考强度**，而不是面板里选的那两个"下次新建会话"用的
  档位。以前两边各说各话，现在一眼能看出终端里到底在什么模式。
- 面板里没有的档（不用问 / 跳过确认）也如实显示；没拿到就写「未知」，绝不拿别的
  值顶上。
- 这一版面板上的强度和权限**仍然只影响下一次新建的会话**——直接改正在跑的那个
  会话是下一版的事。

**安装**：`Clawd-on-Desk-1.3.1-arm64.dmg`（Apple 芯片）。

---

## v1.3.2

- **强度滑块现在直接改终端里正在跑的那个会话**：拖完**松手**时，把 Claude Code
  官方的 `/effort` 命令送进那个会话所在的终端标签页，立刻就改，只对它生效。
- 送不进去会**如实说明**（这个会话够不着 / 没能送进去 / 不支持），并且**不会**
  退化成"把命令悄悄复制到剪贴板、再把终端抢到前面"。
- 权限模式仍然只影响新会话：Claude Code 只有 Shift+Tab 循环切换，盲猜步数有把
  会话切到更宽松模式的风险，所以面板不代劳。

**安装**：`Clawd-on-Desk-1.3.2-arm64.dmg`（Apple 芯片）。

## v1.3.3

面板的会话列表大改，右键菜单也腾出一格。

- **列表能滚了**：以前最多列 4 条会话、多的看不见；现在有几个列几个。
  「＋ 新建会话」和「📁 选择文件夹」钉在卡片下沿，不跟着滚。
- **「最近」那一组**：列出已经结束、但还能接着聊的会话，**点一下就在终端里把它
  重新拉起来**接着聊。拉不起来会如实说卡在哪一步。
- **会话置顶**：鼠标移到任意一行，行尾冒出一个小 📌，点一下钉在列表最上面，
  **重启应用还在**。正在跑的和历史的都能钉。
- **右键菜单**：去掉「打开足迹」（它仍然在设置里），加上「自由漫步」一键开关。

**安装**：`Clawd-on-Desk-1.3.3-arm64.dmg`（Apple 芯片）。
