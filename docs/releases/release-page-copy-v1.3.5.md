## v1.3.5（个人定制版）

这一版把会话列表上的尾巴收干净：**会话起来过又关掉之后，历史里那行不该还挂着
「已提交，等终端上报」**。同时带上上一版的两处修复。

**改过的会话名字，关掉之后不会丢了**

用 Dashboard 双击标题改的名字，以前会话一关就没了——面板和历史列表退回成一串
会话编号（看着像乱码），或者变成你当时打的第一句话那一长串。原因是历史列表的名字
是从对话记录里现读的，压根没查过你起过的名字。现在先查名字，查到就用它。

**续跑回来的会话，不再出现两次**

面板的历史列表是缓存的（免得每次会话动一下就读磁盘）。会话刚被拉起来的那一刻，
缓存里那行还以为自己是"历史"，于是同时显示了一行历史 + 一行刚起来的活会话。
现在每次刷新都拿"当前活着的会话"再滤一遍，会话一活，历史里那行立刻消失。

**续跑状态不会再"挂在旧数据上"**

面板的历史列表是缓存的（免得每次会话动一下就读磁盘），行上"正在等上报"那个标记
是读盘那一刻的快照。会话起来又关掉之后，缓存里还拿着旧的"等着呢"，那行就会先
写着「已提交」、过一会儿才对。

现在不再信缓存里那个标记：每次刷新面板都现算一次，而且**会话只要真的起来过**，
就不会再被当成待确认。另外，点了续跑、终端里还要你手动信任文件夹、会话迟迟不
上报时，超过 30 秒会改口说「还没等到终端上报，可以再试一次」，并且重新可以点。

---

**这个 fork 是什么**：从上游 v1.2.0 起，只改了点桌宠弹出的那块面板——它是**终端里
那个会话的远程输入框**，同时能看能改终端里的真实状态。

- 设置菜单顶部显示终端里**真实的**权限模式与思考强度；拖动强度滑块松手时，官方的
  `/effort` 命令会送进那个会话，立刻就改。
- 会话列表能滚，「＋ 新建会话 / 📁 选择文件夹」钉在卡片下沿。
- 「最近」那一组列出已结束的会话，点一下就在终端里重新拉起来。
- 置顶：每行一个 📌，钉在最上面，重启还在。
- 右键菜单里有「自由漫步」一键开关。

**安装**：`Clawd-on-Desk-1.3.4-arm64.dmg`（Apple 芯片，M 系列）。本地编译、未签名，
双击即可打开；第一次会弹「允许控制终端」的授权，点允许（面板要把消息投递进终端 App）。

**说明**：个人定制版，版本号与上游对不上；自动更新检查指向上游仓库，不会提示更新。
