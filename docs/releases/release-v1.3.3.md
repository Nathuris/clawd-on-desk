## v1.3.3

个人定制版（fork）：**面板的会话列表大改**——能滚、能列历史会话、能一键续跑、
能把常聊的钉在最上面；右键菜单也腾出一格给了「自由漫步」。

### 会话列表能滚了

- 以前只列正在跑的会话、**最多 4 条，多的看不见**；现在整个列表能滚，有几个列几个。
- 「**＋ 新建会话**」和「**📁 选择文件夹**」两行**钉在卡片下沿不动**，滚列表时不会
  跟着跑掉。
- 面板比原来高一点（一眼能看见 5 条）。列表重建时会保住滚动位置——会话状态每变
  一次主进程都会推一份新数据，不处理的话滚动条会被一直顶回顶部。

### 「最近」那一组：历史会话 + 一键续跑

- 列表往下是**历史会话**：已经结束、但还能接着聊的那些。每行写着它在哪个文件夹、
  什么时候结束的。
- **点一下 = 把那个会话重新拉起来接着聊**（和 Dashboard 里点「续跑」是同一套东西）。
  拉的过程中会显示"正在拉起…"，成功显示"已提交，等终端上报"，失败**如实说卡在
  哪一步**（找不到记录 / agent 没启用 / 同时在拉起的太多 / 没能拉起来）。
- 历史行**永远不会变成"发消息的目标"**——点它只有"拉起来"这一个意思，它不会高亮
  （高亮是"消息会发到这里"的标记），也不会出现在顶部状态行里。
- 「记录已经没了」和「记录在不在说不准」**分开说**，不拿"说不准"当"没了"糊弄。
- 条数太多时末尾会明写「还有 N 条更早的会话」，不偷偷少显示。

### 会话置顶（重启还在）

- 鼠标移到任意一行（正在跑的、历史的都行），行尾冒出一个小 **📌**，点一下置顶。
- 置顶的**排在最上面**、重启应用还在。组内**先"活着的"再"历史的"**——上面那拨
  是能直接收消息的，这条界线不让置顶搅乱。
- 点 📌 只改排序：**不选中、不续跑、不碰输入框**。项目文件夹已经删掉的历史会话
  照样能置顶（置顶只是排序偏好，跟能不能续跑是两回事）。

### 右键菜单

- **去掉「打开足迹」**（足迹页面仍然在设置里，只是不再占菜单一格）。
- **加上「自由漫步」一键开关**，紧挨着迷你模式。它和设置里那个开关是同一条偏好，
  两边永远一致。勾上之后桌宠要空闲约 8 秒才开始溜达，鼠标一动就停。
